# Рейтинг классов — ученическое самоуправление гимназии №16

Сайт: https://viccc88.github.io/rating-gymn16/

Баллы, рейтинг и награды берутся из Google-таблицы «Таблица баллов классов 1 корпус 2026-2027» — чтобы изменить что-то на сайте, достаточно отредактировать таблицу.

## Настройка таблицы
1. Доступ: «Все, у кого есть ссылка» → Читатель.
2. Лист **«Награды»**: столбцы `Награда | Цена | Описание | Показывать` (в «Показывать» — `нет`, чтобы скрыть).
3. Лист **«Покупки»**: столбцы `Дата | Класс | Награда | Баллы` — потраченные баллы вычитаются из остатка.
4. Месячные листы называются точно как в `config.js`: «Октябрь 2026» и т.д.

## Как считается
- За год = сумма «Итогового балла» всех месяцев; Потрачено = лист «Покупки»; Остаток = разница.
- Рейтинг — по баллам за год. Новые столбцы-мероприятия появляются на сайте автоматически.

## Настройки
Файл `config.js`: список месяцев, названия листов, заголовки.
